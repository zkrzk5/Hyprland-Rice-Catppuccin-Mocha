# 🌙 Hyprland Rice — Catppuccin Mocha

A clean, minimal Hyprland setup on Arch Linux, themed with Catppuccin Mocha.

## ✨ What's inside

| App | Purpose |
|---|---|
| `hypr` | Window manager config (Hyprland, Hyprlock, Hypridle) |
| `waybar` | Status bar |
| `kitty` | Terminal emulator |
| `nvim` | Neovim config (LazyVim-based) |
| `rofi` | App launcher |
| `btop` | System monitor |
| `cava` | Audio visualizer |
| `fastfetch` | System info fetch |
| `yazi` | Terminal file manager |
| `wallpapers` | My wallpaper collection |

## 📦 Installation

```bash
git clone https://github.com/zkrzk5/Hyprland-Rice-Catppuccin-Mocha.git
cd Hyprland-Rice-Catppuccin-Mocha

for app in btop cava fastfetch hypr kitty nvim rofi waybar yazi; do
  cp -r $app ~/.config/
done

cp -r wallpapers ~/wallpapers
```
